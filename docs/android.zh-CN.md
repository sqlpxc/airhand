# Android（手机 / 平板 / 电视）

[← 返回 README](../README.zh-CN.md) · [English](android.md)

一个 APK（`android/`，构建见[构建 → Android](building.zh-CN.md#androidapk)），装在手机、平板和电视上都可以。同一个应用按打开的方式显示不同的界面：

| 从哪里打开 | 界面 | 能做什么 |
|---|---|---|
| 手机 / 平板的桌面 | 手机界面（三个页签） | **控制别人**：看、操作电脑或别的手机<br>**被控**：共享这台手机的屏幕，让别人看、操作 |
| 电视的桌面（Android TV / Google TV / 电视盒子） | 电视界面，全部用遥控器操作 | **只看画面**（电脑、手机都可以），不能操作，也不能被控 |

电视上从手机桌面的入口打开也会自动转到电视界面。

## 手机：远程

- 首页是一个 **6 位控制码输入框**，输满 6 位就自动连接（也可以点“粘贴控制码”，从“控制码：123 456”这样的文字里找出来）。连接的过程留在首页（按钮上转圈），连上了才进入远程画面；控制码不对、对方不在线、太频繁等原因直接显示在输入框下面
- **配对码**：第一次连接一台电脑或手机时，它会要求输入对方显示的 6 位配对码（电脑在托盘菜单里，手机在“共享本机”页；弹出对话框，电视上数字键盘改成输入配对码），配对之后对方记住这台手机。一台设备的身份和上次连接时不一样（重装过，或者有人冒充它）时，要输入它现在的配对码重新配对。会话是端到端加密的：中转服务器看不到画面，也看不到你打的字
- **我的设备**：连接成功的设备自动保存（名称、系统、控制码、上次连接时间、重连凭证、对方的端到端加密公钥），下次**点一下就连**。对方不在线时设备上显示“对方不在线 · 上线后自动连接”，对方一上线就自动进入远程画面，可以随时取消。每台设备可以重命名、复制控制码、删除（删除后可以撤销）
- 正在连接的会话在首页顶部有一张卡片，点一下回到远程画面

远程画面全屏显示，只有一个**可以拖动的小圆钮**（松手后贴到左 / 右边），点开是菜单：键盘、快捷键、声音、音画同步、画质（预设与桌面版相同，可以选编码格式，见[使用说明](usage.zh-CN.md)的画质面板）、剪贴板（同步到对方剪贴板 / 作为键盘输入发送）、显示器（多屏时）、锁定鼠标和游戏按键（控制电脑时）、防窥模式（对方是 Windows、Mac 时）、适应屏幕、手势说明、断开。菜单顶部显示对方名称和编码格式、帧率、延迟、码率、走的路。手机转到横屏时画面自动铺满。

**文件**：对方复制的文件放进手机的剪贴板，可以在别的应用里粘贴；通知里可以“保存到下载”（文件夹只能这样）。手机上的文件在文件管理器、相册里**分享 → 发给对方**，再到对方那里粘贴（手机共享屏幕时也一样，发给正在控制本机的设备）。复制时只发清单，粘贴时才传（见[使用说明 → 复制粘贴文件](usage.zh-CN.md#复制粘贴文件)）。

两种**操作方式**（菜单里的两个大按钮随时切换，设置里可以选默认；默认“自动”：控制电脑用触控板，控制手机用触屏），第一次使用时会先显示手势说明：

| 手势 | 触控板（控制电脑） | 触屏（控制电脑） | 触屏（控制手机） |
|---|---|---|---|
| 单指滑动 | 移动指针（慢精细、快加速） | 按住左键拖动 | 每个手指都原样传过去：点按、长按、滑动、双指缩放、多指手势都作用在对方手机上 |
| 单击 | 左键单击，点两下 = 双击 | 在手指处单击 | 〃 |
| 长按 | 右键 | 在手指处右键 | 〃 |
| 点一下再按住拖动 | 按住左键拖动（选文字、拖窗口） | — | 〃 |
| 双指点击 | 右键 | 右键 | 〃 |
| 双指拖动 | 滚动（自然滚动，松手后有惯性） | 滚动 | 〃 |
| 双指捏合 | 放大画面，画面跟着指针走 | 放大 / 移动画面 | 〃 |
| 三指点击 | 打开 / 收起键盘 | 同左 | 〃（键盘在菜单里打开） |

对方是 Android 7 的手机时（系统不支持连续的多指手势）只传一个手指，双指捏合 / 移动只缩放本机的画面。

双指放大本机的画面之后，手指停下一会儿就向对方要更清楚的画面（按放大后的大小，720p / 1080p / 1440p / 4K 往上取，最多到对方屏幕的原始分辨率，本机解码器放不下时会小一些），缩回去之后恢复画质设置里的分辨率。码率上限不变：画面在动时可能比原来糊一点，静止下来几帧之内就补清楚。

- 触控板模式下指针由本机画出来（形状来自对方），移动没有延迟；触屏模式点按处有一个淡出的圆作为反馈
- **键盘**：打开后画面缩到键盘上方，始终能看到全貌；键盘上面多一排特殊键：Esc、Tab、Ctrl、Alt、Shift、Win（Mac 上是 ⌘）、方向键、Home / End、PgUp / PgDn、Del、F1–F12。修饰键是“粘滞”的：点一下只对下一个键有效，再点一下锁定，再点取消（例如点 Ctrl 再在键盘上打 c = Ctrl+C）。拼音等输入法组字时文字显示在特殊键上方，选好字才发过去
- 控制手机时画面下方有**返回 / 主页 / 最近任务**三个键（设置里可以关掉），快捷键菜单里是通知栏、快捷设置、截屏、锁屏、电源菜单、音量等系统操作（对方手机能执行哪些就显示哪些）；控制电脑时快捷键菜单按对方系统列出（Windows / macOS / Linux）
- 外接鼠标、键盘直接对应远端的鼠标、键盘。鼠标在画面上时只显示对方的光标，不会再叠一个系统指针；滚轮的方向和速度可以在设置里改。键盘上 Ctrl / ⌘ 的组合键不会被本机的输入法拿走；打开菜单、切到后台时按着的键都会松开。控制 Mac 时，菜单里的**快捷键 → 互换 Ctrl 和 ⌘ Command** 让键盘上的 Ctrl 当 ⌘ 用、Win 键当 Ctrl 用（用 Windows 键盘按 Ctrl+C 复制）；键盘上方的特殊键和菜单里的快捷键不变。默认关闭，每台电脑分别记住，和桌面控制台一样
- **游戏**：对方电脑隐藏了光标时（游戏里转视角），触控板的滑动、触屏的拖动发的是“移动了多少”而不是位置，视角转得顺，拖到画面边上也不会停；外接鼠标会被抓住（Android 8+）。菜单里的**锁定鼠标**让它一直这样，例如对方是 Mac（检测不到光标隐藏）时。要按键盘的游戏用下面的游戏按键
- **防窥模式**：对方是 Windows、Mac（而且是支持它的版本）时菜单里有它。打开后对方所有的显示器黑屏、键盘鼠标不起作用，只有你看得到、操作得了；开关下面写着现在怎么样（正在打开、开着、开不了的原因），没能打开时画面上方也会提示。断开连接后自动恢复，断线重连时接着保持。详见[使用说明 → 防窥模式](usage.zh-CN.md#防窥模式)
- 返回键会先问“断开连接？”，不会误触断开。网络断了自动重连；对方离线了显示“已离线，对方上线后自动连接”；对方断开了你或者换了控制码时说明原因，不再重连
- 应用切到后台时会话保留，画面降到每秒 2 帧、声音暂停，回来时马上恢复
- **音画同步**默认关闭，可在会话菜单或设置里打开并记住选择。播放声音时按实际输出进度对齐画面，画面持续落后时让声音适量等待；看视频时适合开启，会增加操作延迟。关闭声音、进入后台或断线重连时重新测量同步时钟
- 声音使用自适应抖动缓冲（与桌面控制台同一套做法）：每个包按采集时刻量晚到量，缓冲马上加大到能盖住，最近约一分钟里最大的晚到量也是回落的下限，偶尔卡一下的不会一回落就又断；轻微变速抵消时钟漂移，严重积压时跳过旧声音，短提示音也会播放

### 游戏按键

控制电脑时，菜单里的**游戏按键**可以在画面上叠一层按钮和摇杆，用手机玩要按键盘的游戏（WASD 走路、空格跳、按住 Shift 跑……）。只在控制端：发的是协议里已有的按键、鼠标键、滚轮和相对移动，被控端不用升级，Windows 上按扫描码注入，游戏认得。

- **按钮**：按住就是按着那个键，松手就松开；可以是键盘上的键、鼠标键、滚轮（按着会一格一格地转下去），也可以是组合键（最多 3 个，按顺序按下、倒序松开，例如 Ctrl+1）。每个按钮可以选“点一下切换”（点一下按下、再点一下松开，自动奔跑、一直蹲着这类），切换着的按钮外面有一圈主题色。手指从按钮上滑出去也不会松开（开火时拇指会挪）
- **摇杆**：WASD 或方向键，8 个方向（斜着推同时按两个），方向边界和中间的死区都有回差，拇指在边界上抖也不会让键来回按；可以设“推出边缘时加按”一个键（Shift 奔跑等）；默认从拇指落下的地方开始，不用正好按在中间
- **转视角**：手指没落在按钮上时照常操作（触控板 / 触屏）。游戏隐藏了光标时，空白处拖动就是转视角：只发移动量、不按左键、不加速，乘上方案里的灵敏度；快速点一下仍是左键，拇指停着不动不算长按（不会误开镜），慢慢松开也不算点击（不会误开枪）。按钮可以设“拖动可以转视角”：射击模板的开火键按住拖动就是一边开火一边瞄准
- 同一个键被几处按着（摇杆的 W 和一个 W 按钮）时都松开才松开。打开菜单、拉下通知栏、切到后台、断线、打开键盘、换方案时，按着的键（包括切换着的）全部松开，角色不会一直走下去
- 摇杆和按钮所在的地方不让系统的返回手势抢走（手势导航时从屏幕边滑入是返回）；按钮避开刘海
- **方案**：第一次用时有三套模板——射击（WASD 摇杆，推出边缘奔跑；开火、开镜、跳、蹲、换弹、E、Q、武器 1–3、Tab、Esc）、技能（MOBA / ARPG：Q W E R、D F、物品 1–4、B、空格，点画面就是点击）、方向键（横版 / 模拟器：方向键摇杆、Z X C、空格、回车、Esc），可以新建（从模板或者空白开始）、复制、重命名、删除。每台电脑分别记住开没开、用哪个方案
- **编辑布局**（游戏按键页 → 编辑布局）：画面压暗、铺一层点阵，拖动按钮摆放（靠近别的按钮或者画面中线时吸过去，画出对齐线，轻振一下），双指捏合调选中的按钮的大小，点一下按钮在另一边弹出它的设置（按键、按钮上的文字、按住 / 点一下切换、拖动可以转视角、大小；摇杆是方向键、推出边缘加按、从按下的地方开始、大小），还可以复制、删除。工具栏：撤销（每一步都能撤销）、添加（选键，或者摇杆）、方案设置（名称、不透明度、转视角灵敏度、按下时振动）、取消、完成；工具栏挡住按钮时按着左边的把手拖开。改的是一份副本，点“完成”才保存，有改动时取消会先确认
- 第一次打开时有一页说明

## 手机：共享本机（被控）

“共享本机”页点**开始共享屏幕**：先请求通知和录音权限（录音只用来共享**手机正在播放的声音**，不录麦克风；拒绝也能共享画面），然后是系统的录屏确认。开始后：

- 大字显示本机的**控制码**，可以复制、分享；控制码像 Windows 安装版一样**固定不变**（保存在应用自己的数据目录里，服务器一直为这台手机保留），直到点“更换控制码”
- **配对码**，和电脑一样：只凭控制码谁也进不来（中转服务器知道所有控制码），第一次连接本机的设备还要输入这个 6 位配对码，它从不经过服务器。配对之后手机记住那台设备（认的是它在端到端加密握手里的公钥，中转服务器冒充不了），以后只要控制码，停止共享再开始也一样。分享时两个码一起发。有人连续输错 5 次配对码时配对暂停，点**换一个配对码**就恢复。**忘掉已配对的设备**（这里或者设置里）之后它们要重新输入配对码；**更换控制码**时配对码也换一个、配对过的全部忘掉。“全部断开”只是断开，配对过的设备之后还能连回来
- 有设备连上来时弹出**通知**：是谁、能看还是能操作、从哪个 IP 来，还有**安全码**（对方显示的是同一个，不一样就是中间有人），带“全部断开”。同一台设备断线重连只更新那一条、不再响；对方走了通知还留着，看得到谁来过
- 显示**谁在看**（名称、IP、安全码），可以全部断开；通知栏里一直有“正在共享 · 控制码”和“停止共享”
- 有人在看时保持屏幕亮着（息屏后录不到画面）；没人看时不采集、不编码
- 下面是**权限清单**，每一项说明用途、状态和“去开启”：
  - **远程操作**（无障碍服务）：开启后对方才能点按、滑动、输入文字，否则只能看（对方会看到提示）。Android 13 起，不是从应用商店安装的应用要先在“应用信息 → 右上角 ⋮ → 允许受限制的设置”里放行，引导里有说明和直达按钮
  - **共享声音**（Android 10+，录音权限）
  - **通知**（Android 13+）
  - **后台运行**（忽略电池优化）：避免锁屏或切到后台后被系统停止

对方的操作这样对应到手机上：触摸点和鼠标左键都是手指（可以点、长按、拖动、滑动，几个手指同时按就是多点触控），滚轮 = 滑动；返回、主页、最近任务、通知栏、截屏等是协议里的**系统操作**，由控制端的导航键和快捷键菜单发出（桌面控制台的快捷键菜单在对方是手机时也列出这些）。为了方便电脑上的人，右键 / Esc = 返回，中键 / 单按 Win = 主页，Alt+Tab = 最近任务，Ctrl+C / V / X / A = 复制 / 粘贴 / 剪切 / 全选；打字直接写进当前的输入框（桌面版按的物理键按美式键盘换算成字符）。

## 手机：设置

服务器地址和证书指纹（编译时设置默认值，这里可以改；指纹格式不对时不能保存；留空时第一次连接记住服务器的证书，之后证书变了就拒绝连接，重新保存一次指纹会忘掉记住的证书）、本机名称（对方看到的名字，默认是系统里的设备名称）、更换控制码（配对码也换一个、配对过的全部忘掉）、配对过的设备（有几台，可以全部忘掉）、默认画质、默认操作方式、是否默认播放声音、音画同步、控制手机时显示导航键、拖动窗口时显示本地光标（默认打开：Windows 被控端把光标画进画面里时照样画触控板的光标）、鼠标滚轮的方向和速度（外接鼠标）、清除已保存的设备、版本和协议版本。

## 电视

- 左边输入控制码：遥控器的数字键直接输入，或者用屏幕上的数字键盘；右边是最近连接的设备，方向键选中、确认键连接；要删除某台设备，按它右边的删除按钮，或者在设备上长按确认键 / 按菜单键（会先确认）；右上角是设置（服务器、指纹、本机名称）
- 画面全屏显示，默认打开声音。**确认键 / 菜单键**打开右侧菜单：声音、音画同步、显示器、画质（按一下换一档）、编码格式（自动 / 双方都支持的各种格式，按一下换一个）、画面缩放（完整显示 / 铺满（裁掉边缘）/ 拉伸全屏）、显示连接信息、断开；编码格式和画面缩放会记下来，以后的连接也用；**左 / 右**切换对方的显示器；**返回键**关闭菜单，再按一次确认断开
- 电视只看不操作：对方没有开启远程操作（手机的无障碍服务、Mac 的“辅助功能”）时不会提示

## 数据保存在哪里

设置（`settings.json`）、保存的设备（`devices.json`）、本机的控制码和取回它用的密钥（`host.json`）、配对码和配对过的设备（`pairing.json`）、游戏按键的方案（`game.json`）都只放在应用自己的私有目录（`/data/data/app.airhand.android/files/`）里，别的应用读不到。清单里关闭了备份和设备迁移，**卸载应用时系统会把这些全部删除**。日志只写到 logcat。
