# Android（手机 / 平板 / 电视）

[← 返回 README](../README.zh-CN.md) · [English](android.md)

一个 APK（`android/`，构建见[构建 → Android](building.zh-CN.md#androidapk)），装在手机、平板和电视上都可以。同一个应用按打开的方式显示不同的界面：

| 从哪里打开 | 界面 | 能做什么 |
|---|---|---|
| 手机 / 平板的桌面 | 手机界面（三个页签） | **控制别人**：看、操作电脑或别的手机<br>**被控**：共享这台手机的屏幕，让别人看、操作 |
| 电视的桌面（Android TV / Google TV / 电视盒子） | 电视界面，全部用遥控器操作 | **只看画面**（电脑、手机都可以），不能操作，也不能被控 |

电视上从手机桌面的入口打开也会自动转到电视界面。

## 手机：远程

- 首页是一个 **6 位控制码输入框**，输满 6 位就自动连接（也可以点“粘贴控制码”，从“控制码：123 456”这样的文字里找出来）。连接的过程留在首页（按钮上转圈），连上了才进入远程画面；控制码不对、对方不在线、太频繁等原因直接显示在输入框下面
- **配对码**：第一次连接一台电脑时，它会要求输入它托盘菜单里的 6 位配对码（弹出对话框；电视上数字键盘改成输入配对码），配对之后它记住这台手机。一台电脑的身份和上次连接时不一样（重装过，或者有人冒充它）时，要输入它现在的配对码重新配对。会话是端到端加密的：中转服务器看不到画面，也看不到你打的字
- **我的设备**：连接成功的设备自动保存（名称、系统、控制码、上次连接时间、重连凭证、对方的端到端加密公钥），下次**点一下就连**。对方不在线时设备上显示“对方不在线 · 上线后自动连接”，对方一上线就自动进入远程画面，可以随时取消。每台设备可以重命名、复制控制码、删除（删除后可以撤销）
- 正在连接的会话在首页顶部有一张卡片，点一下回到远程画面

远程画面全屏显示，只有一个**可以拖动的小圆钮**（松手后贴到左 / 右边），点开是菜单：键盘、快捷键、声音、音画同步、画质（预设与桌面版相同，可以选缩放优先（低延迟 / 文字清晰，对方是电脑时才有，见[使用说明](usage.zh-CN.md)的画质面板）和编码格式）、剪贴板（同步到对方剪贴板 / 作为键盘输入发送）、显示器（多屏时）、适应屏幕、手势说明、断开。菜单顶部显示对方名称和编码格式、帧率、延迟、码率。手机转到横屏时画面自动铺满。

两种**操作方式**（菜单里的两个大按钮随时切换，设置里可以选默认；默认“自动”：控制电脑用触控板，控制手机用触屏），第一次使用时会先显示手势说明：

| 手势 | 触控板（控制电脑） | 触屏（控制电脑） | 触屏（控制手机） |
|---|---|---|---|
| 单指滑动 | 移动指针（慢精细、快加速） | 按住左键拖动 | 每个手指都原样传过去：点按、长按、滑动、双指缩放、多指手势都作用在对方手机上 |
| 单击 | 左键单击，点两下 = 双击 | 在手指处单击 | 〃 |
| 长按 | 右键 | 在手指处右键 | 〃 |
| 点一下再按住拖动 | 按住左键拖动（选文字、拖窗口） | — | 〃 |
| 双指点击 | 右键 | 右键 | 〃 |
| 双指拖动 | 滚动（自然滚动，松手后有惯性） | 滚动 | 〃 |
| 双指捏合 | 放大画面，画面跟着指针走 | 放大 / 移动画面 | 〃 |
| 三指点击 | 打开 / 收起键盘 | 同左 | 〃（键盘在菜单里打开） |

对方是 Android 7 的手机时（系统不支持连续的多指手势）只传一个手指，双指捏合 / 移动只缩放本机的画面。

双指放大本机的画面之后，手指停下一会儿就向对方要更清楚的画面（按放大后的大小，720p / 1080p / 1440p / 4K 往上取，最多到对方屏幕的原始分辨率，本机解码器放不下时会小一些），缩回去之后恢复画质设置里的分辨率。码率上限不变：画面在动时可能比原来糊一点，静止下来几帧之内就补清楚。

- 触控板模式下指针由本机画出来（形状来自对方），移动没有延迟；触屏模式点按处有一个淡出的圆作为反馈
- **键盘**：打开后画面缩到键盘上方，始终能看到全貌；键盘上面多一排特殊键：Esc、Tab、Ctrl、Alt、Shift、Win（Mac 上是 ⌘）、方向键、Home / End、PgUp / PgDn、Del、F1–F12。修饰键是“粘滞”的：点一下只对下一个键有效，再点一下锁定，再点取消（例如点 Ctrl 再在键盘上打 c = Ctrl+C）。拼音等输入法组字时文字显示在特殊键上方，选好字才发过去
- 控制手机时画面下方有**返回 / 主页 / 最近任务**三个键（设置里可以关掉），快捷键菜单里是通知栏、快捷设置、截屏、锁屏、电源菜单、音量等系统操作（对方手机能执行哪些就显示哪些）；控制电脑时快捷键菜单按对方系统列出（Windows / macOS / Linux）
- 对方手机设置了“连接前先问我”时，首页显示“等待对方同意…”（可以取消），对方同意后才进入远程画面；对方拒绝或 60 秒没理会时说明原因
- 外接鼠标、键盘直接对应远端的鼠标、键盘
- **游戏**：对方电脑隐藏了光标时（游戏里转视角），触控板的滑动、触屏的拖动发的是“移动了多少”而不是位置，视角转得顺，拖到画面边上也不会停；外接鼠标会被抓住（Android 8+）。菜单里的**锁定鼠标**让它一直这样，例如对方是 Mac（检测不到光标隐藏）时
- 返回键会先问“断开连接？”，不会误触断开。网络断了自动重连；对方离线了显示“已离线，对方上线后自动连接”；对方断开了你或者换了控制码时说明原因，不再重连
- 应用切到后台时会话保留，画面降到每秒 2 帧、声音暂停，回来时马上恢复
- **音画同步**默认关闭，可在会话菜单或设置里打开并记住选择。播放声音时按实际输出进度对齐画面，画面持续落后时让声音适量等待；看视频时适合开启，会增加操作延迟。关闭声音、进入后台或断线重连时重新测量同步时钟
- 声音使用自适应抖动缓冲（与桌面控制台同一套做法）：每个包按采集时刻量晚到量，缓冲马上加大到能盖住，最近约一分钟里最大的晚到量也是回落的下限，偶尔卡一下的不会一回落就又断；轻微变速抵消时钟漂移，严重积压时跳过旧声音，短提示音也会播放

## 手机：共享本机（被控）

“共享本机”页点**开始共享屏幕**：先请求通知和录音权限（录音只用来共享**手机正在播放的声音**，不录麦克风；拒绝也能共享画面），然后是系统的录屏确认。开始后：

- 大字显示本机的**控制码**，可以复制、分享；控制码像 Windows 安装版一样**固定不变**（保存在应用自己的数据目录里，服务器一直为这台手机保留），直到点“更换控制码”
- **连接前先问我**（默认开启，设置里可以关）：有人输入本机控制码时，弹出通知并在这一页显示“XX 请求连接”，写明对方能看还是能操作、从哪个 IP 来，还有**安全码**（对方屏幕上显示的是同一个，不一样就是中间有人），由你**允许**或**拒绝**；60 秒不处理自动拒绝。同意之前对方看不到画面，也不能操作。同时最多有 2 个请求在等你处理，再来的直接回绝（对方过一会儿可以再试）。允许过的设备在这次共享里断线重连不再询问（认的是它在端到端加密握手里的公钥，中转服务器冒充不了）；停止共享、全部断开或更换控制码之后都要重新允许
- 显示**谁在看**（名称、IP），可以全部断开；通知栏里一直有“正在共享 · 控制码”和“停止共享”
- 有人在看时保持屏幕亮着（息屏后录不到画面）；没人看时不采集、不编码
- 下面是**权限清单**，每一项说明用途、状态和“去开启”：
  - **远程操作**（无障碍服务）：开启后对方才能点按、滑动、输入文字，否则只能看（对方会看到提示）。Android 13 起，不是从应用商店安装的应用要先在“应用信息 → 右上角 ⋮ → 允许受限制的设置”里放行，引导里有说明和直达按钮
  - **共享声音**（Android 10+，录音权限）
  - **通知**（Android 13+）
  - **后台运行**（忽略电池优化）：避免锁屏或切到后台后被系统停止

对方的操作这样对应到手机上：触摸点和鼠标左键都是手指（可以点、长按、拖动、滑动，几个手指同时按就是多点触控），滚轮 = 滑动；返回、主页、最近任务、通知栏、截屏等是协议里的**系统操作**，由控制端的导航键和快捷键菜单发出（桌面控制台的快捷键菜单在对方是手机时也列出这些）。为了方便电脑上的人，右键 / Esc = 返回，中键 / 单按 Win = 主页，Alt+Tab = 最近任务，Ctrl+C / V / X / A = 复制 / 粘贴 / 剪切 / 全选；打字直接写进当前的输入框（桌面版按的物理键按美式键盘换算成字符）。

## 手机：设置

服务器地址和证书指纹（编译时设置默认值，这里可以改；指纹格式不对时不能保存；留空时第一次连接记住服务器的证书，之后证书变了就拒绝连接，重新保存一次指纹会忘掉记住的证书）、本机名称（对方看到的名字，默认是系统里的设备名称）、连接前先问我、更换控制码、默认画质、缩放优先、默认操作方式、是否默认播放声音、音画同步、控制手机时显示导航键、清除已保存的设备、版本和协议版本。

## 电视

- 左边输入控制码：遥控器的数字键直接输入，或者用屏幕上的数字键盘；右边是最近连接的设备，方向键选中、确认键连接；要删除某台设备，按它右边的删除按钮，或者在设备上长按确认键 / 按菜单键（会先确认）；右上角是设置（服务器、指纹、本机名称）
- 画面全屏显示，默认打开声音。**确认键 / 菜单键**打开右侧菜单：声音、音画同步、显示器、画质（按一下换一档）、缩放优先（低延迟 / 文字清晰，对方是电脑时才有）、编码格式（自动 / 双方都支持的各种格式，按一下换一个）、画面缩放（完整显示 / 铺满（裁掉边缘）/ 拉伸全屏）、显示连接信息、断开；缩放优先、编码格式和画面缩放会记下来，以后的连接也用；**左 / 右**切换对方的显示器；**返回键**关闭菜单，再按一次确认断开
- 电视只看不操作：对方没有开启远程操作（手机的无障碍服务、Mac 的“辅助功能”）时不会提示

## 数据保存在哪里

设置（`settings.json`）、保存的设备（`devices.json`）、本机的控制码和取回它用的密钥（`host.json`）都只放在应用自己的私有目录（`/data/data/app.airhand.android/files/`）里，别的应用读不到。清单里关闭了备份和设备迁移，**卸载应用时系统会把这些全部删除**。日志只写到 logcat。
