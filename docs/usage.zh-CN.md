# 使用指南

[← 返回 README](../README.zh-CN.md) · [English](usage.md)

## 被控端（默认）

双击运行（Windows 要先安装，见 [Windows 安装版](#windows-安装版)），右下角（macOS 是屏幕顶部的菜单栏，Linux 是顶栏 / 任务栏的状态区）出现托盘图标：灰色表示没连上服务器，彩色表示已连接。右键（macOS 上单击）菜单里有：

- 服务器状态（macOS、Linux 上还有当前模式）
- **控制码**和“复制控制码”
- **配对码**、“复制配对码”和**更换配对码**：没配对过的控制端第一次连接本机时，除了控制码还要输入配对码（见下面的“配对”）
- 正在控制本机的控制端（连接后面是**安全码**），以及**断开所有控制端**
- **更换控制码**：旧码立即失效，已连接的控制端会被断开；配对码也换一个，配对过的控制端全部忘掉
- **忘掉已配对的控制端**：它们下次连接要重新输入配对码
- 打开控制台、**开机自动启动**（Windows；仅为自己安装时是**登录时自动启动**）/ 切换为控制端（macOS、Linux）、**登录时自动启动**（macOS）/ **结束远程后锁屏**（见下面）/ **不自动睡眠**（macOS，见下面）/ 语言 / **卸载 Airhand…**（macOS，见[卸载](#卸载)）/ 退出

掉线后会按指数退避自动重连，并且**取回原来的控制码**（服务器重启后也能取回）。控制码是**固定的**：保存在 `config.toml` 里，服务器为这台电脑一直保留它，离线多久都不会分给别人（180 天没有上线才释放），所以重启、升级之后都不变，直到你主动更换。

**配对**：控制码是中转服务器分配的，服务器知道所有控制码，所以只凭控制码不能连上本机（否则服务器自己就能连上来）。一台控制端第一次连接本机时，要输入托盘菜单里的 6 位**配对码**；配对码不经过服务器。配对之后本机记住这台控制端，以后只要控制码。有人连续输错 5 次配对码时配对会暂停，托盘里会提示，换一个配对码就恢复。配对不能关掉。详见[安全 → 端到端加密](security.zh-CN.md#端到端加密)。

**结束远程后锁屏**（默认开启）：远程控制结束后本机自动锁屏，[防窥模式](#防窥模式)也随之退出（先锁屏、再恢复显示器，本机的桌面不会露出来）。控制端断开时马上锁；断线时等它重连 30 秒，没连回来才锁；还有别的控制端连着时不锁。本机断开所有控制端、退出 Airhand 时有控制端连着也会锁屏。不想锁屏：在托盘菜单里取消勾选**结束远程后锁屏**，马上生效（记在 `config.toml` 的 `lock_on_end` 里，见[配置文件](#配置文件)）。

> Linux 的托盘图标走 AppIndicator：Ubuntu、KDE、Xfce 等开箱即用，原版 GNOME 需要装 “AppIndicator and KStatusNotifierItem Support” 扩展。没有 AppIndicator 库时程序照常作为被控端运行，控制码打印在日志（stderr）里。

> macOS 上被控端需要两项系统权限：**屏幕与系统录音**（采集画面和声音）和**辅助功能**（操作键盘鼠标）。第一次启动时系统会弹窗询问；没有授权时菜单里会有提示，点一下就打开“系统设置 → 隐私与安全性”里对应的页面；连上来的控制端也会看到对方缺少哪一项权限（按控制端自己的语言显示），对方授权后提示自动消失。授予“屏幕与系统录音”后需要重新打开 Airhand。Airhand 平时只在菜单栏里，打开控制台时才出现在程序坞中。

> macOS 上的**登录时自动启动**（菜单栏图标的菜单里切换）：登录后 Airhand 自动在菜单栏里运行，本机重启之后照样能被控制（macOS 上程序只能在登录之后运行，登录界面本来也采集不了；Mac 设置了自动登录的话就相当于开机启动）。它就是“系统设置 → 通用 → 登录项”（有的系统版本叫“登录项与扩展”）里“登录时打开”的那一项，在那里关掉也一样，菜单会跟着变。**第一次从“应用程序”文件夹运行时默认打开**（系统会弹出“已添加登录项”的通知），只打开这一次：之后你关掉了就一直关着，Airhand 不会自己再打开。只有放在“应用程序”文件夹（`/Applications` 或 `~/Applications`）里的 Airhand 才能打开它：从下载目录、磁盘映像里直接打开的，系统会把它挪到临时位置运行，登记了下次也找不到，菜单里会提示先拖进“应用程序”文件夹。

> macOS 上的**锁屏和睡眠**：有控制端连着时 Mac 不会因为没人碰键盘鼠标而熄屏、睡眠。Mac 锁着屏也能控制：屏幕熄了的话，控制端连上来时 Airhand 会叫醒它，你看到的是锁屏界面，输入密码就解锁了（开着**结束远程后锁屏**的话，断开之后又会锁上）。但 Mac **睡眠**了就离线了（程序被冻结，和服务器的连接也断了），控制端连不上，只能等它醒来。想让它一直能被连接：在菜单栏图标的菜单里勾选**不自动睡眠**（默认关，马上生效，记在 `config.toml` 的 `prevent_sleep` 里），Airhand 作为被控端运行、接着电源时 Mac 不因为空闲而睡眠，合上笔记本的盖子也不睡，显示器照常熄灭；用电池时照常睡眠。效果和系统设置里的“防止在显示器关闭时自动进入睡眠”（台式机在“节能”里，笔记本在“电池 → 选项”里）差不多，只是只在 Airhand 运行时生效，合盖也管，不改系统设置。在苹果菜单里选“睡眠”、用电池时合上盖子、电量低时照样睡眠。
>
> **防窥模式**：控制端打开后（见[防窥模式](#防窥模式)），本机所有的显示器变黑（背光还亮着），每个显示器上还盖着一个黑色的窗口；本机的键盘、鼠标、触控板不起作用，控制端照样看得到、操作得了。要允许 Airhand 使用**辅助功能**（被控端操作键盘鼠标本来就要它），没有的话控制端的开关是灰的。不改显示设置：Airhand 退出（包括崩溃）时显示器、键盘鼠标马上恢复。
>
> **远程控制时合上盖子**（MacBook）：接着电源的话 Mac 接着运行，照样能控制。接着电源、没接外接显示器的 MacBook 有控制端连着时（开着**不自动睡眠**的话，Airhand 作为被控端运行期间一直都是，合上盖子之后才连上来也有画面），Airhand 备着一块镜像内建显示器的虚拟显示器（系统设置 → 显示器里叫 “Airhand”；加上、撤掉它时屏幕可能闪一下；镜像期间 120 Hz 的屏幕可能只有 60 Hz），平时看不出来，控制端看到的也还是一个显示器。合上盖子时系统换到它上面，窗口挪过去，控制端照样看得到、操作得了，声音也照常；打开盖子系统又换回来。没接显示器的 Mac（Mac mini）也会补上一块。没开**不自动睡眠**的话，最后一个控制端断开之后它再留 30 秒（等重连），之后合着盖子的 Mac 照常睡眠。用电池时合上盖子照样睡眠。

## Windows 安装版

Windows 上用安装程序安装，可以为所有用户安装，也可以仅为自己安装：

| | 为所有用户安装（推荐） | 仅为我安装 |
|---|---|---|
| 管理员权限 | 需要 | 不需要 |
| 装到 | `C:\Program Files\Airhand`，所有用户共用 | `%LOCALAPPDATA%\Programs\Airhand`，只有你用 |
| 被控端 | 系统服务：锁屏、登录界面和 UAC 确认框也能控制 | 在托盘进程里、以你的身份运行：锁屏、登录界面和 UAC 确认框不能控制，以管理员身份运行的窗口只能看、不能操作 |
| 自动启动 | 开机自动启动，登录之前就能被控制 | 你登录时自动启动 |
| 安装目录 | 只能在 Program Files 里：服务以 SYSTEM 身份运行这里的程序，别的位置普通用户可能改得了它 | 不能在 Program Files、Windows 文件夹里：设置要保存在程序旁边 |

- **第一次安装**：管理员账户在安装程序里选择安装方式（默认为所有用户安装）。普通账户运行时安装程序先问一句：选“是”就以管理员身份重新运行（要输入管理员密码），为所有用户安装；选“否”仅为你安装
- **升级、重新安装**：按原来的方式安装，不再询问。为所有用户安装的那份需要管理员权限，普通账户运行时会先说明，再要求输入管理员密码。升级前托盘开着的话，装好后自动重新打开（远程帮别人升级时，连接随之恢复）
- **换安装方式**：先卸载，再重新安装

### 为所有用户安装

被控端作为系统服务 **Airhand** 运行：以 SYSTEM 身份运行在当前坐在屏幕前的用户的会话里，所以锁屏、登录界面和 UAC 确认框上也能照常控制，切换用户时也会跟过去。托盘图标是一个普通程序，显示服务的状态、操作服务：

- 打开 Airhand 时启动服务；托盘里**退出**时停止服务（和以前一样，退出后本机不能再被控制）；服务停止（或者被卸载）时托盘也随之退出
- **开机自动启动**（托盘菜单，默认开启）：开机时启动服务，登录之前就能被控制；登录后出现托盘图标。在任务管理器的“启动应用”里禁用 Airhand 只是登录后不打开托盘（服务照样开机启动），托盘菜单里的勾不会跟着变：在菜单里关掉再打开开机自动启动，就恢复了
- 配置文件 `config.toml` 在安装目录里（安装时生成，见[配置文件](#配置文件)），由服务维护；要用管理员身份修改
- **卸载**（设置 → 应用）会停止并删除服务、开机启动项、`config.toml` 和程序，不留下任何东西（虚拟显示器驱动由你选择删不删，见[卸载](#卸载)）。在旧版本上安装新版本时保留 `config.toml`（也就保留了控制码和我的设备），选择“先卸载旧版本”也一样
- **虚拟显示器驱动**：第一次安装时安装程序会问要不要装，见下面的[虚拟显示器](#虚拟显示器)

### 仅为我安装

- 被控端在托盘进程里运行：托盘里**退出**后本机不能再被控制；打开控制台时照常运行，和为所有用户安装时一样。托盘菜单最上面写着“仅为当前用户安装”
- **登录时自动启动**（托盘菜单，默认开启）：你登录后 Airhand 自动运行。在任务管理器的“启动应用”里禁用了 Airhand 的话，托盘菜单里的勾不会跟着变：在菜单里关掉再打开，就恢复了
- 配置文件 `config.toml` 也在安装目录里（见[配置文件](#配置文件)），由托盘维护，可以直接修改
- 卸载、升级和为所有用户安装时一样（见[卸载](#卸载)）
- 别的用户又为所有用户安装了 Airhand 的话，仅为你安装的这一份不再运行（否则两个被控端同时运行），也不再登录时自动启动，并问你要不要卸载它。正在运行时也一样：发现之后马上停下被控端

### 虚拟显示器

为所有用户安装时，安装程序会问要不要装**虚拟显示器驱动**（来自开源项目 [Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver)，MIT 许可，随安装包带着）。它平时停用着、不显示任何东西，只在下面两种情况下由被控端临时启用：

- **显示器关了电源也能远程控制**：很多显示器（尤其是 DP 接口的）关了电源，Windows 就把它从桌面上移走，没有桌面可以采集。装了驱动以后，有控制端连着、本机又没有显示器在桌面上时（关了电源、拔了线、根本没接），Airhand 自动启用一块虚拟显示器补上，分辨率和刚才的显示器一样；控制端的画面几秒钟之后就换到它上面。显示器重新打开、最后一个控制端断开 30 秒后，虚拟显示器自己停用
- **防窥模式**：控制端打开后，本机所有的显示器都黑屏（没有信号），本机的键盘鼠标不起作用，只有控制端看得到、操作得了（见控制端的[防窥模式](#防窥模式)）

另外，有控制端连着的时候 Windows 不会因为没人碰键盘鼠标而熄屏、睡眠（这一条不需要驱动）：熄了屏画面就停住了，支持现代待机的电脑熄屏就进入待机、连接也就断了。合上笔记本的盖子、按电源键这些你自己让电脑睡眠的照样睡眠；要合着盖子也能控制，在“电源选项 → 选择关闭笔记本计算机盖的功能”里选“不采取任何操作”。

- **安装**：第一次为所有用户安装时问一次（升级时不再问）。选“是”之后 Windows 可能还会问是否安装发布者为“SignPath Foundation”的设备软件（驱动的签名不是微软的），选安装。当时没装的话，以后以管理员身份运行 `"C:\Program Files\Airhand\airhand.exe" --install-vdd` 就能装上（装好后在托盘里退出 Airhand 再打开）；仅为我安装时用不了（启用、停用设备要管理员权限）
- **卸载**：卸载 Airhand 时有一页“同时删除虚拟显示器驱动”，默认不勾（留着的话，重新安装时不用再装）。不勾也会先把它停用，不会多出一块显示器。留下的驱动以后可以在设备管理器的“显示适配器”里卸载（勾选“删除此设备的驱动程序”）
- 这台电脑上已经有别的程序（例如 Sunshine）装的 Virtual Display Driver 时，Airhand 不动它，也就用不了上面这两样
- 驱动的设置在 `%ProgramData%\Airhand\VirtualDisplay` 里，由 Airhand 维护

没有安装的 `airhand.exe` 不能直接运行：发布版会提示运行安装程序。调试构建（`npm run tauri dev`）和 macOS、Linux 一样在托盘进程里运行被控端，`config.toml` 放在程序旁边（`client/src-tauri/target/debug/`）

## 配置文件

Airhand 要保存的东西都在一个 `config.toml` 里（里面有注释）。控制台左上角的菜单里也能看到它的位置：

| 系统 | 位置 |
|---|---|
| Windows | 安装目录：`C:\Program Files\Airhand\config.toml`，仅为我安装时是 `%LOCALAPPDATA%\Programs\Airhand\config.toml`（没有安装的调试构建在程序旁边） |
| macOS | `~/Library/Application Support/app.airhand.client/config.toml` |
| Linux | `$XDG_CONFIG_HOME/airhand/config.toml`，默认 `~/.config/airhand/config.toml` |

| 键 | 说明 |
|---|---|
| `server` | 中转服务器 `host:port`；不设置时使用编译进程序的地址 |
| `server_fp` | 中转服务器的证书指纹；`""` 表示不固定指纹：第一次连接时记住服务器的证书（`[server_trust]`），之后证书变了就拒绝连接；不设置时使用编译进程序的指纹 |
| `[server_trust]` | 由 Airhand 写入：没有设置指纹时，第一次连上中转服务器时记下的证书指纹。服务器确实换了证书时删掉这一段 |
| `autostart` | Windows：开机自动启动，仅为我安装时是登录时自动启动（托盘菜单里也可以切换）。macOS：登录时自动启动的记录，以系统设置为准，只改这一项不起作用；没有这一项表示还没有按默认打开过（见上面） |
| `language` | 界面语言，`"zh"` 或 `"en"`：在托盘菜单或控制台里选语言时写入（见[界面语言](#界面语言)）。没有这一项就跟随系统语言。Windows 上为所有用户安装时本机所有账户共用（文件是共用的） |
| `privacy_mode` | Windows、macOS：允许控制端打开[防窥模式](#防窥模式)，默认 `true`。文件里默认没有这一项：不想让别人开防窥模式时手动写上 `privacy_mode = false` |
| `lock_on_end` | 远程控制结束后锁屏（见[被控端](#被控端默认)）：在托盘菜单里切换**结束远程后锁屏**时写入。没有这一项就是 `true`（锁屏） |
| `prevent_sleep` | macOS：不自动睡眠（见[被控端](#被控端默认)的“锁屏和睡眠”）：在菜单栏图标的菜单里切换**不自动睡眠**时写入。打开时接着电源的 Mac 不因为空闲睡眠，合上盖子也不睡。没有这一项就是 `false`（照常睡眠） |
| `[code]` | 本机的控制码，以及取回它用的密钥。删掉 `code` 和 `secret` 就会重新分配 |
| `[host]` | 由 Airhand 维护：本机作为被控端的端到端加密身份（`key`）、配对码和它有没有暂停，都是加密保存的。删掉 `key` 会生成新的身份：连过本机的控制端会提示本机的身份变了 |
| `[[paired]]` | 由 Airhand 维护：配对过的控制端（公钥、名称、配对的时间），不用配对码就能连。删掉一项就是忘掉那个控制端 |
| `[controller]` | 由 Airhand 维护：控制台的端到端加密身份（加密保存，Windows 上每个账户一把）。配对过的电脑靠它认出这个控制台，删掉了就要重新配对 |
| `[[device]]` | 控制台的**我的设备**：连接过的电脑（控制码、对方的名字、自己起的名字、上次的画质、最后连接的时间、对方的公钥 `host_key`），连上时自动保存，最多 50 台。手动添加时 `code` 写 6 位数字就行 |

- 改了设置要重新启动 Airhand 才生效（退出，再打开）。Airhand 保存控制码和设备时会保留你改过的内容和注释
- **不小心删掉了**（这个文件或者整个目录）：启动时、以及运行中几秒之内，按默认配置重新生成；本机的控制码、开机自动启动（macOS 是登录时自动启动的记录）、界面语言、端到端加密的身份、配对过的控制端和我的设备从删掉之前的内容接着用，不会丢，其余设置回到默认
- 控制码能直接控制对应的电脑，相当于钥匙。macOS / Linux 上只有你的账户能读写这个文件（权限 600，目录 700）。Windows 上文件在安装目录里，为所有用户安装时本机的所有账户都能读：本机的密钥用 SYSTEM 账户（仅为我安装时是你的账户）的 DPAPI 加密，我的设备里的控制码用保存它的那个 Windows 账户加密，别的账户、别的电脑都解不开（同一台电脑上每个账户只看得到自己的设备）
- Windows 卸载时删除；macOS / Linux 上删掉程序后它还在（系统的惯例），要一起删掉，见[卸载](#卸载)

## 卸载

按下面的步骤做完，Airhand 在这台电脑上不会留下什么（macOS 上有两样受系统保护的东西 Airhand 删不掉，见 [macOS](#macos) 的最后）。配置文件里有本机的控制码和“我的设备”里别的电脑的控制码（相当于钥匙），不再用 Airhand 的话请一定删掉。

### Windows

设置 → 应用 → Airhand → 卸载。卸载程序会停止并删除系统服务 Airhand（仅为我安装时是让托盘退出）、开机（登录时）启动项（包括任务管理器“启动应用”里对它的启用 / 禁用记录，不删的话重新安装后它还是被禁用的），删除安装目录（包括 `config.toml`）、安装程序写的注册表项、Windows 防火墙里为 `airhand.exe` 添加的规则，以及控制台的临时目录。不用再手动做什么。

装过[虚拟显示器](#虚拟显示器)驱动的话，卸载程序在确认卸载之前有一页“同时删除虚拟显示器驱动”，默认不勾：不勾就留着停用了的驱动（还有注册表里认得它的记录 `HKLM\SOFTWARE\Airhand\VirtualDisplay` 和它的设置 `%ProgramData%\Airhand\VirtualDisplay`），重新安装 Airhand 时接着用；勾上就一起删掉。

（升级时选择“先卸载旧版本”不算卸载：会保留 `config.toml`，见 [Windows 安装版](#windows-安装版)。）

### macOS

macOS 的 App 没有卸载程序，拖进废纸篓只删掉了程序本身。除了程序，Airhand 在 macOS 上还会留下这几样（按卸载的顺序）：

| 项目 | 位置 | 说明 |
|---|---|---|
| 未完成的文件接收 | 所选文件夹下的 `.airhand-receive-<随机编号>`，配置目录里对应的 `pending-receive-<随机编号>` 指向它 | 取消、退出或卸载会清理临时内容，保留已接收的项目。强制退出后下次启动会重试。若接收时拔掉了外置盘，请先重新接上。 |
| Airhand Microphone | Core Audio 录音设备和对应的音频 tap | 退出时移除；若曾强制退出，下次启动或从菜单卸载时会清理当前用户的残留 |
| 登录时自动启动 | “系统设置 → 通用 → 登录项”（有的系统版本叫“登录项与扩展”）里“登录时打开”和“后台 App 活动”两处 | 要由 Airhand 自己注销：先删掉 App 的话，两处都会留下一个失效的 Airhand |
| 权限记录 | “系统设置 → 隐私与安全性”里的“屏幕与系统录音”“辅助功能”等 | 要在 App 还在的时候清除，App 删掉之后系统就找不到它了 |
| 配置文件 | `~/Library/Application Support/app.airhand.client/` | 里面有控制码，一定要删 |
| 系统为它生成的缓存 | 系统的缓存目录和临时目录（`getconf DARWIN_USER_CACHE_DIR`、`DARWIN_USER_TEMP_DIR`）里的 `*app.airhand.client` | Metal、WebKit 以 Airhand 的名字建的，大多是空的，最多是一点 GPU 着色器缓存。临时目录里 WebKit 的几个删不掉，见最后 |
| 崩溃报告 | `~/Library/Logs/DiagnosticReports/airhand-*.ips`、`~/Library/Application Support/CrashReporter/airhand_*.plist` | 只有 Airhand 崩溃过才有 |
| 菜单栏图标的设置 | `~/Library/Preferences/app.airhand.client.plist` | Airhand 自己不用这个文件，平时也没有：按住 ⌘ 拖动过菜单栏图标（记下位置）、或者在“系统设置 → 菜单栏”里关掉过它（记下不显示）时由系统写入。不删的话，重新安装后图标还是藏着的 |

**用菜单卸载**：点菜单栏里的 Airhand 图标，选**卸载 Airhand…**，确认之后会按上表的顺序全部清掉（受系统保护、删不掉的跳过，见最后），再把 Airhand 移到废纸篓并退出，清空废纸篓就彻底删掉了。哪一项没做成，最后的提示里会列出来，用下面手动卸载里对应的命令补上。

**手动卸载**：Airhand 打不开、或者想自己动手时用。前两步要在删掉 App 之前做，**顺序不能乱**。

1. 点菜单栏里的 Airhand 图标，**关掉“登录时自动启动”**，然后选**退出**（旧版本的菜单里没有这一项，也就没有登记过登录项，直接退出）。
2. 打开“终端”，清除权限记录（只影响 Airhand）：

   ```bash
   tccutil reset All app.airhand.client
   ```

   看到 `Successfully reset All approval status for app.airhand.client` 就好了。如果提示 `No such bundle identifier`，说明 App 已经删掉了，见下面的“已经直接删掉了 App”。
3. 若上次接收文件时强制退出，先打开 Airhand 一次让它清理未完成的传输，再退出。手动清理时可用 `find "$HOME/Library/Application Support/app.airhand.client" -maxdepth 1 -type l -name 'pending-receive-*' -exec readlink {} \;` 查看此次传输的隐藏临时目录，可在访达里前往并删除该临时目录。保留同级的已接收文件。
4. 删除其余几样和程序：

   ```bash
   rm -rf ~/Library/Application\ Support/app.airhand.client
   find "$(getconf DARWIN_USER_CACHE_DIR)" "$(getconf DARWIN_USER_TEMP_DIR)" -maxdepth 1 -name '*app.airhand.client' -exec rm -rf {} + 2>/dev/null
   find ~/Library/Logs/DiagnosticReports ~/Library/Application\ Support/CrashReporter -maxdepth 1 -name 'airhand[-_]*' -delete 2>/dev/null
   defaults delete app.airhand.client 2>/dev/null; rm -f ~/Library/Preferences/app.airhand.client.plist
   rm -rf /Applications/Airhand.app ~/Applications/Airhand.app
   ```

   一行一项，依次是配置文件、系统为它生成的缓存、崩溃报告、菜单栏图标的设置和程序。最后一行也可以换成在“应用程序”文件夹里把 Airhand 拖进废纸篓（再清空废纸篓）。`find` 会碰到别的 App 受保护的目录，那些报错已经忽略了，不影响结果。菜单栏图标的设置先用 `defaults delete` 经过系统的偏好设置服务删，它会留下一个空文件，再用 `rm` 删掉。

**检查**：下面的命令除了临时目录里 WebKit 的几个空目录（删不掉，见最后）之外什么都不输出，并且“系统设置 → 通用 → 登录项”和“隐私与安全性 → 屏幕与系统录音 / 辅助功能”里都没有 Airhand，就是删干净了。

```bash
ls -d ~/Library/Application\ Support/app.airhand.client ~/Library/Preferences/app.airhand.client.plist /Applications/Airhand.app ~/Applications/Airhand.app 2>/dev/null
find "$(getconf DARWIN_USER_CACHE_DIR)" "$(getconf DARWIN_USER_TEMP_DIR)" -maxdepth 1 -name '*app.airhand.client' 2>/dev/null
find ~/Library/Logs/DiagnosticReports ~/Library/Application\ Support/CrashReporter -maxdepth 1 -name 'airhand[-_]*' 2>/dev/null
```

**已经直接删掉了 App**（没有先做第 1、2 步）：把 Airhand.app 重新放回原来的位置（例如从下载的 `.dmg` 里再拖进“应用程序”文件夹），打开它，再从第 1 步做起。系统还记着原来的登录项，在菜单里关掉就会把“登录时打开”和“后台 App 活动”里的两处一起删掉。不想再装一次的话也可以手动删：“登录项”里在“登录时打开”中选中 Airhand 点“−”，“隐私与安全性 → 屏幕与系统录音 / 辅助功能”里选中 Airhand 点“−”，然后做第 3、4 步。

**Airhand 删不掉的**：下面两样受系统保护。

- 系统临时目录里 WebKit 的几个目录 `com.apple.WebKit.*+app.airhand.client`（打开过控制台才有）：有系统完整性保护（SIP），谁都删不掉，删除时提示 `Operation not permitted`，用菜单卸载时会跳过它们。里面是空的；用到 WebKit 的 App（包括 Safari）在这里都有这样的目录。
- macOS 26 起，“系统设置 → 菜单栏”里允许在菜单栏显示的 App 列表（Allow in the Menu Bar）可能还有 Airhand。这份列表由系统记在受保护的文件里，系统没有提供删除单个 App 的办法，只能按下面的方法把整个列表重置。它只是一条记录，不重置也不影响什么；以后重新安装时，如果之前在这里关掉过 Airhand，菜单栏里不会出现它的图标，在这里重新打开就行。

**重置菜单栏的 App 列表**（可选，macOS 26 起）：这个列表记在 `~/Library/Group Containers/group.com.apple.controlcenter/Library/Preferences/group.com.apple.controlcenter.plist` 的 `trackedApplications` 一项里。删掉这一项、注销再登录之后列表就清空了，以后有菜单栏图标的 App 运行时会重新加进来，已经删掉的 App 不会再出现。这不是苹果提供的功能，而是改系统自己的文件，**会把所有 App 在这个列表里的选择一起清掉**：之前关掉的菜单栏图标会重新出现，要再到“系统设置 → 菜单栏”里关一遍。

1. 给“终端”完全磁盘访问权限：在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”里打开“终端”（列表里没有就点“+”添加“应用程序 → 实用工具 → 终端”），然后退出终端再重新打开。这个文件在受保护的目录里，没有这个权限读不到也改不了。
2. 退出“系统设置”，在终端里先备份，再删掉这一项：

   ```bash
   cd ~/Library/Group\ Containers/group.com.apple.controlcenter/Library/Preferences
   cp group.com.apple.controlcenter.plist ~/group.com.apple.controlcenter.plist.bak
   defaults delete "$PWD/group.com.apple.controlcenter.plist" trackedApplications
   ```

   要用 `defaults` 删，不要直接改文件：系统的偏好设置服务里还缓存着它，直接改文件的话，可能又被缓存里的旧内容写回来。
3. 注销再登录（或者重新启动），再打开“系统设置 → 菜单栏”看一下。
4. 回到“完全磁盘访问权限”里把“终端”关掉。

想恢复原来的列表：同样在有完全磁盘访问权限的终端里运行 `defaults import ~/Library/Group\ Containers/group.com.apple.controlcenter/Library/Preferences/group.com.apple.controlcenter.plist ~/group.com.apple.controlcenter.plist.bak`，再注销、登录。

### Linux

```bash
sudo apt remove airhand     # 删除程序（.deb 安装的）
rm -rf "${XDG_CONFIG_HOME:-$HOME/.config}/airhand"  # 删除当前用户的配置和配对记录
```

卸载 `.deb` 时会先停止已安装的 Airhand 进程，PipeWire 随连接关闭移除虚拟麦克风。Linux 上没有开机启动项和系统权限要清理。托盘图标、控制台的临时目录（`$XDG_RUNTIME_DIR/airhand-run-*`、`/tmp/airhand-webview-*`）在 Airhand 退出时就删掉了，对方复制过来的文件所在的 FUSE 挂载点（`$XDG_RUNTIME_DIR/airhand-clip/<进程号>`）也在退出时卸掉；只有进程被强制结束过才会留下（下次启动时会清理），通常注销 / 重启时系统也会清空它们，也可以手动清理（先卸掉挂载点再删）：`fusermount3 -uz "$XDG_RUNTIME_DIR"/airhand-clip/* 2>/dev/null; rm -rf "$XDG_RUNTIME_DIR"/airhand-run-* "$XDG_RUNTIME_DIR"/airhand-clip /tmp/airhand-webview-*`。

### Android

在系统里卸载应用即可：设置、保存的设备、本机的控制码都在应用的私有目录里，系统会全部删除（见 [Android → 数据保存在哪里](android.zh-CN.md#数据保存在哪里)）；“远程操作”用的无障碍服务也随应用一起移除。

## 控制端

托盘 → **切换为控制端**，打开控制台。关闭控制台窗口会回到被控端模式。Windows 上，双击 Airhand 托盘图标或在右键菜单中选择**打开控制台**即可。控制台已打开时，双击会将窗口带到前台。Windows 上被控端在此期间照常运行（为所有用户安装、仅为自己安装都一样），本机照样能被控制；macOS、Linux 上切换为控制端时被控端暂停，关掉控制台后恢复。

- 界面和浏览器一样：每台电脑一个**标签**，可以拖动排序，中键或 × 关闭（= 断开）。点 **+** 新建连接，输入 6 位控制码（可以直接粘贴 `123 456`），连上后这个标签就变成那台电脑。连着两台以上时最左边有**多屏总览**标签
- **第一次连接一台电脑或手机**：对方会要求配对码（所有被控端都这样），新建连接页上多出一栏“配对码”，输入对方显示的 6 位配对码（电脑在托盘菜单里，手机在 Airhand 的“共享本机”页）再连（也可以一次粘贴 12 位：控制码 + 配对码）。配对之后对方记住本机，以后不用再输
- **端到端加密**：会话是端到端加密的，中转服务器看不到画面和键盘输入。第一次连上一台电脑时记下它的身份；之后它的身份变了（重装过，或者有人冒充它），控制台会提示、不会自动重连，确认是对方重装了之后，输入对方现在的配对码（电脑在托盘里，手机在“共享本机”页）重新配对。鼠标停在工具栏的控制码上能看到**安全码**，和对方显示的一样（电脑在托盘里，手机在“谁在看”列表里）就说明中间没有人
- **我的设备**：连接过的电脑自动保存（在 `config.toml` 里），下次在新建连接页点一下就连，用上次的画质；可以重命名、移除（能撤销），设备多了可以搜索。对方不在线时不报错：打开标签等它上线，一上线就连上（带着上次的重连凭证，不算猜码）
- 窗口没有系统标题栏：拖动标签栏的空白处移动窗口，双击最大化。最左边的图标是菜单：本机名称、服务器状态、语言、切换为被控端。还有连接时关闭控制台（包括任务栏、Alt+F4）会先确认
- 快捷键（不在操作远程电脑时）：Ctrl+T 新建连接、Ctrl+W 关闭标签、Ctrl+Tab / Ctrl+Shift+Tab 切换标签、Ctrl+1~9、Ctrl+Shift+T 重新打开刚关闭的连接。远程画面有焦点时按键都发给对方
- 工具栏（像地址栏）：对方名称、控制码、帧率 / 码率 / 延迟、编码器；显示器切换（对方有好几个显示器时，见下面的[多屏](#多屏)）、**画质**、快捷键、剪贴板（双向同步 / 以键盘输入方式发送）、声音（静音 / 音画同步）、麦克风（对方能接时才有，见下面的[麦克风](#麦克风)）、防窥模式（对方是 Windows、Mac 时才有，见下面的[防窥模式](#防窥模式)）、鼠标（见下面的[鼠标](#鼠标)）、1:1 原始大小、全屏、断开
- 控制 Mac 时，工具栏的**发送快捷键 → 互换 Ctrl 和 ⌘ Command** 默认关闭。开启后，Windows 键盘的 Ctrl+C 在对方执行 ⌘C，Win 键则作为 Control；菜单里的快捷键不变。桌面版按设备记住，网页版只记到刷新页面为止。
- 全屏时标签栏隐藏，鼠标移到屏幕顶端出现工具栏，点对方名称可以切换到其它连接（仍然全屏）。全屏时会尝试锁定键盘，Win 键、Alt+Tab 这类系统快捷键也发给远端。macOS 上全屏不另开桌面空间，系统菜单栏和程序坞不出现（免得挡住工具栏和远程的任务栏，切到别的程序时照常显示），用工具栏的按钮退出全屏；点窗口绿色按钮进入的是系统全屏，菜单栏、程序坞照常
- **玩游戏**：默认的自动模式在对方隐藏光标时（游戏里转视角）自动锁定鼠标；常玩游戏的电脑可以换成游戏模式，见下面的[鼠标](#鼠标)
- 网络抖动导致的断开会自动重连；被控端的用户断开了你时，控制台会说明原因，不再重连
- 对方电脑离线了（关机、睡眠、断网）：控制台显示“等待对方重新上线”，对方一上线（取回原来的控制码）就自动连上。等待期间不会反复尝试，也不会被服务器当成猜码而限速
- 配对之后连手机不用对方点什么；连上时手机会弹通知，写着本机的名字和安全码。控制手机时快捷键菜单里是返回、主页、通知栏等系统操作

**画质面板**：预设从省流（720p / 24 fps / 1.2 Mbps）、均衡（1080p / 30 fps / 4 Mbps）、流畅（1080p / 60 fps / 8 Mbps）、高清（1440p / 60 fps / 16 Mbps）到原画（原始分辨率 / 60 fps / 30 Mbps），也可以自己调分辨率上限、帧率（15–120）、码率上限（0.5–100 Mbps）、编码格式和自适应码率。控制台只提供本机能硬件解码的格式；被控端没有对应的硬件编码器时会自动回退，工具栏上显示实际用的编码器。

对方的屏幕比请求的分辨率大时，被控端会尽量在显卡上缩放，以降低延迟；无法使用显卡时自动用 CPU 缩放。

丢包时 QUIC 会重传。持续缺帧时，被控端从控制端已有的参考帧恢复，编码器没有可用参考帧时发送关键帧。

分辨率上限之外，画面也不会超过它在窗口里实际显示的大小：窗口比对方的屏幕小时，被控端直接把画面缩到窗口的大小，控制台按 1:1 显示，不再缩放第二次（文字更清楚，也更省带宽）。拖动窗口边框时，停下来之后才切换分辨率。切换为“原始大小（1:1）”时不受窗口限制。

**画面增强（本机）**：关 / 弱 / 中 / 强，默认关。画面比窗口小、要放大显示时（例如用 1080p 的预设全屏看 2K / 4K 屏），在这台电脑的显卡上用更锐利的算法（Catmull-Rom）放大，再按亮度适度锐化文字边缘；1:1 显示时只锐化。不增加带宽，对延迟几乎没有影响。太强会让压缩的痕迹（块状、文字边上的毛刺）更明显，码率低时选弱。只作用于正在操作的连接（多屏总览的缩略图不处理），对所有连接生效，选择记在这台电脑上。浏览器不支持 WebGL2 时退回浏览器自己的高质量缩放（不锐化）。想要画面真正更清楚，还是要提高分辨率上限和码率：增强只能让收到的画面显示得更好。

### 鼠标

工具栏的鼠标按钮（图标随模式变）选怎么用鼠标。选择按设备记住，下次连这台电脑还用它：

- **自动**（默认）：平时跟着这台电脑的指针，对方的光标就在你指的地方，移动不延迟。对方隐藏光标时（例如魔兽世界里按住右键转视角、第一人称游戏）自动锁定本机指针、改发“移动了多少”，拖多远都不会碰到屏幕边停下；对方的光标重新出现时自动放开（按着鼠标键时等松开再放开，转视角不会中途被打断）
- **桌面**：一直跟着这台电脑的指针，从不锁定。对方的程序会隐藏光标、但不该锁定时用它，例如看视频、画图、一些设计软件
- **游戏**：一直锁定本机指针、发“移动了多少”，对方把它自己的光标画进画面里：看到的就是对方真实的光标，游戏里转视角、点界面都不用切换，只在开始时锁定一次（浏览器的“按 Esc 显示光标”提示只出现一次）。光标跟着画面走，比本机指针慢一个来回，帧率低时也没那么顺，画质选 60 fps 更好。对方是 Mac（检测不到光标隐藏）、或者游戏不隐藏光标时也用它

锁定时**长按 Esc**（约 1 秒）放开鼠标（全屏时键盘被锁定，短按的 Esc 照常发给对方，游戏要用）：自动模式到下一次点击之前不再自动锁定；游戏模式下鼠标先不发给对方，画面下方提示“点击画面锁定鼠标”，点一下重新锁定（这一下不发给对方，免得在游戏里误点）。**Ctrl+Alt+Shift+M** 进入 / 退出游戏模式（退出时回到原来的模式）。

**画面里有光标时也显示本机光标**（鼠标菜单里，默认打开）：对方是 Windows 时，拖动、缩放窗口期间它会把光标直接画进画面里。打开时照样显示这台电脑的光标，跟手不延迟，只是和画面里那个（稍慢一点）一起有两个；关闭时只看画面里的那个。不管开不开，鼠标都照常按位置操作，不会锁定。游戏模式下用不到。对所有连接生效，选择记在这台电脑上。

### 多屏

对方有好几个显示器时，工具栏上有显示器按钮。默认只看一个：在菜单里点哪个就看哪个。打开菜单底部的**同时显示所有显示器**，所有显示器的画面一起显示，按它们在对方桌面上的位置拼在一起（左右、上下错开都和对方一样），整体缩放到窗口里；鼠标移到哪一块上就是在操作哪个显示器，从一块移到相邻的一块和在对方电脑上一样，键盘、剪贴板、声音和只看一个时一样。再点某一个显示器回到只看它。

- 每个显示器是单独的一路画面：各自编码、各自调码率、丢包时各自恢复，互不影响。画质设置对每一路分别生效，所以同时看两个显示器大约要两倍的带宽（自适应码率会按网络情况把每一路调下来）；每一路的分辨率按它在窗口里显示的大小要
- 最多同时显示 4 个显示器（对方是手机时只有一个）
- 对方插拔显示器时会跟着变：拔掉的那一块不再显示，新插上的在“同时显示所有显示器”时自动加进来
- 全屏、1:1 原始大小（可以滚动）、多屏总览的缩略图都照样可用；画面增强对每一块分别处理

**单独的窗口**：本机也有好几个显示器时，可以把对方的显示器分别放到单独的窗口里，一个窗口放到本机的一个显示器上、各自全屏。点显示器菜单里那个显示器右边的按钮，它就到了一个新窗口里（桌面版会放到控制台不在的那个显示器上），主窗口里显示剩下的。新窗口顶上有全屏和放回主窗口的按钮；全屏时和主窗口一样，鼠标碰到屏幕顶端出现工具栏。关掉这个窗口也就放回了主窗口。

- 不用另外连一次：还是同一个连接，只是那一路画面画在了另一个窗口里，带宽和同时显示几个显示器时一样
- 只看一个显示器时也能把另一个放到单独的窗口里（多要一路画面）；主窗口里至少要留一个显示器
- 鼠标、键盘在哪个窗口里就操作那个窗口里的显示器；画质、声音、快捷键这些在主窗口的工具栏里
- 网页版要允许这个网站打开弹出窗口

### 复制粘贴文件

剪贴板同步打开时（工具栏的剪贴板按钮，默认打开），文件、文件夹也能复制粘贴，两个方向都行：在这台电脑上复制，到对方的资源管理器 / 文件管理器里粘贴；或者在对方那里复制，到这台电脑上粘贴。

- 复制时只把清单发过去，粘贴时才开始传，进度条和取消按钮是粘贴的那个文件管理器自己的。复制了不粘贴就不传
- 两边直连通着时（见[工作原理 → 直连](architecture.zh-CN.md#直连)）多大都行。只能经过中转服务器时，一次粘贴最多传服务器允许的大小（默认 50 MiB，见部署说明的 `AIRHAND_MAX_FILE_SIZE`），超过了会提示
- 复制之后又改过的文件传不了，重新复制一次
- 文件夹里的快捷方式、符号链接不会把它指向的东西带过去
- **网页控制台**：在远程画面上按 Ctrl+V（Mac 上 ⌘V）把本机复制的文件粘贴过去，也可以把文件、文件夹拖到画面上；对方复制了文件时画面上方出现提示，点**下载**取下来（Chrome / Edge 可以选存到哪个文件夹）
- **Android**：对方复制的文件进手机的剪贴板，可以在别的应用里粘贴；通知里可以**保存到下载**（文件夹只能这样）。手机上的文件在文件管理器、相册里**分享 → 发给对方**，再到对方那里粘贴
- **Mac 接收文件**：连接期间在 Windows 等对端复制文件或文件夹，在 Mac 屏幕顶部点 **Airhand → 接收文件到…**，选好目标文件夹再点**接收**。传输期间可在同一菜单取消。每个顶层项目完整接收后才显示，同名项目自动编号。Mac 上复制的文件仍可到对方的文件管理器粘贴。

具体的限制见[已知限制](limitations.zh-CN.md)。

### 麦克风

把这台电脑的麦克风发给对方：对方电脑上的程序（开会、语音输入、发语音消息）把录音设备选成它的虚拟麦克风，就能听到你说话。默认关闭，每个连接单独打开（工具栏的麦克风按钮 → **把本机麦克风发给对方**），只在正在查看那个连接时发送；第一次打开时浏览器会问能不能用麦克风（桌面版不问）。

- Windows 被控端使用 Steam 自带的 **Steam Streaming Microphone**（Valve 提供、微软签名的虚拟麦克风驱动）。打开转发时，如果设备尚未就绪，Airhand 会从对方电脑的 Steam 安装目录查找并安装驱动。设备就绪后会自动开始转发。对方电脑上缺少 Steam 时，麦克风菜单会提示安装 Steam
- 在对方电脑的程序里把录音设备选成“麦克风 (Steam Streaming Microphone)”（英文系统是 “Microphone (Steam Streaming Microphone)”），或者在那台电脑的“声音设置 → 输入”里把它设为默认，Windows 的语音输入（Win+H）等用默认麦克风的程序就直接听得到
- 同一时刻只给一个控制端；别的控制端打开时会显示“另一个控制端正在用”，那个关掉之后自动换过来
- **macOS 14.2+ 和 Linux（PipeWire）**：打开转发后，在对方的会议或录音软件里选择 **Airhand Microphone**。Mac 首次使用时可能要允许该软件录制系统音频。关闭转发或断开连接后设备会移除。Linux 结束 Airhand 进程后由 PipeWire 自动移除；Mac 强制退出后，重新打开 Airhand 或使用菜单里的“卸载 Airhand…”会清理残留。
- Android 被控端和 Android 控制端目前还不支持麦克风转发。

### 防窥模式

让对方电脑前的人看不到你在做什么：对方所有的显示器黑屏，对方的键盘鼠标不起作用，只有你看得到、操作得了。工具栏的盾牌按钮 → **防窥模式**；手机上（Android、iPhone / iPad）是画面边上的圆钮 → **防窥模式**，开关下面写着现在的状态。

- Windows 被控端要为所有用户安装、安装时装上了[虚拟显示器](#虚拟显示器)驱动；Mac 被控端要允许 Airhand 使用“辅助功能”（操作它的键盘鼠标本来就要）。不满足时开关是灰的，菜单里写着为什么。对方是 Linux、手机时没有这个按钮
- **Windows**：打开时对方启用一块虚拟显示器（分辨率和对方的主显示器一样），只留它在桌面上，把本机的显示器都撤下来（没有信号），要几秒钟；你看到、操作的就是这块虚拟显示器。开始菜单、UAC 确认框、锁屏、鼠标指针也都在它上面，对方的显示器上什么都没有。对方的键盘鼠标被挡住，但 Ctrl+Alt+Del 挡不住（Windows 的安全键）：按了只是切到安全桌面，对方的显示器上也看不到
- **Mac**：马上就打开，你看到、操作的还是对方原来的显示器，画面不变；对方的显示器调成全黑（背光还亮着），每个显示器上还盖着一个黑色的窗口（只有你这边看不到它）。对方的键盘、鼠标、触控板（包括媒体键、手势）被挡住。挡不住的情况见[已知限制](limitations.zh-CN.md#macos)
- 整台电脑一个开关：几个控制端同时连着时看到的是同一个状态，哪一个都能关
- **自动结束**：远程控制结束时自动关闭（你断开时马上关；断线时等你重连 30 秒），而且先锁屏、再恢复对方的显示器，对方的显示器亮起来时已经是锁屏界面（对方在托盘菜单里取消了**结束远程后锁屏**时不锁屏，见[被控端](#被控端默认)）。断线重连时控制台在连接的时候就告诉对方接着开着，对方的屏幕不会在重连的间隙里露出来
- 控制端没断开就没了（例如手机上直接划掉了 Airhand）：对方大约 10 秒后发现连接断了。这时对方电脑前的人按一下键盘、点一下鼠标就马上结束（先锁屏、再恢复显示器），不用等 30 秒；发现之前就按过的也算
- 对方电脑前的人要结束它：断开那台电脑的网络，会话断开之后按一下键盘（锁着屏），或者重启它（Windows 上 Airhand 启动时会把显示器恢复原样；Mac 上 Airhand 一退出就恢复了）
- 不想让别人对这台电脑开防窥模式：在它的 `config.toml` 里写上 `privacy_mode = false`（见[配置文件](#配置文件)）

## 界面语言

控制台和托盘菜单支持**简体中文**和**英文**。默认跟随系统显示语言：系统是中文就用中文，否则用英文。可以在托盘菜单“语言 / Language”或控制台菜单（左上角的图标）里的“中文 / EN”随时切换。选的语言记在 `config.toml` 里（`language`），以后一直用它；删掉这一项就重新跟随系统语言。

对方电脑和服务器发来的提示、错误都是消息类型而不是文字，所以总是按**你自己**的语言显示。日志（客户端和服务端）统一是英文。
